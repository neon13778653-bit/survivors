================================================
  SURVIVORS — survival-like игра в браузере
  ПОЛНАЯ ВЕРСИЯ (игра + все ресурсы)
================================================

ЗАПУСК
------
1. Распакуйте архив ЦЕЛИКОМ в любую папку
   (все файлы должны лежать рядом с index.html).
2. Откройте index.html в современном браузере
   (Chrome, Firefox, Edge или Safari).
3. Играйте! Интернет не нужен — игра, спрайты,
   иконки и шрифты лежат в самой папке.

УПРАВЛЕНИЕ
----------
- Движение: WASD или стрелки
- Все остальные подсказки — на стартовом экране игры

СОХРАНЕНИЯ
----------
Прогресс (монеты, улучшения, питомцы) сохраняется автоматически
в браузере через localStorage. Не очищайте данные сайта, если
хотите сохранить прогресс. Прогресс не переносится вместе с
архивом — он живёт в браузере.

СОСТАВ ПРОЕКТА
--------------
index.html            — Главная точка входа (Canvas 2D + WebAudio + игровой интерфейс)
js/platform.js        — Универсальный Global SDK мост (Poki, CrazyGames, Telegram TMA, GD, FB Instant, Web)
css/game_fonts.css    — Таблица стилей локальных игровых шрифтов
fonts/                — Файлы шрифтов (Rajdhani, Russo One) в формате .woff2
img/                  — Каталог всей графики игры (оптимизирована в WebP):
  ├── heroes/         — Спрайтшиты, портреты, оверлеи рук героев (54 файла)
  ├── weapons/        — Модели и иконки оружия (40 файлов)
  ├── monsters/       — Спрайты врагов, боссов, зомби (35 файлов)
  ├── pets/           — Иконки и спрайты питомцев (17 файлов)
  ├── shields/        — Иконки щитов (5 файлов)
  ├── artifacts/      — Иконки артефактов (20 файлов)
  ├── ui/             — Иконки меню, дока, ящики, аирдропы (16 файлов)
  ├── backgrounds/    — Фоны уровней (3 файла)
  └── abilities/      — Иконки всех 94 способностей (94 файла)
_png_backup/          — Резервная копия исходных несжатых PNG (не нужна для релиза)

Установка не требуется. Просто откройте index.html.
