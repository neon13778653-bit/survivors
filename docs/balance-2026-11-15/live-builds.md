# Сборки в живых волнах

150 полных забегов в игровом цикле при 30 кадрах/с. Для каждой строки использованы одинаковые пять начальных значений генератора случайных чисел (101, 202, 303, 404, 505). После разных действий последовательности выдачи могут расходиться. Джон, одинаковое управление, только выпавшие карты. Бот подбирает опыт, открывает видимые ящики, обходит врагов и кружит вокруг босса. Эволюции имеют первый приоритет. Затем бот выбирает карту своего профиля, при её отсутствии предпочитает усиление уже выбранной карты. Все фактические карты, волны, время, здоровье и исход записаны в соседних JSON.

Базовый комплект — баклер и слизень, без артефактов, пять постоянных улучшений по 5/20. Полный комплект — Эгида, Древень, Корона, Ядро Сингулярности и Перо Феникса, постоянные улучшения по 20/20. Предметы без улучшений кузницы. Комплекты заданы на старте, без симуляции стоимости получения.
