# Survivors

Браузерная survival-игра на Canvas 2D и WebAudio. Откройте `index.html` в современном браузере; ресурсы и шрифты находятся в проекте.

В обычном режиме новый прогресс начинается с первой главы. Следующие главы открываются через предусмотренную игрой покупку или победу в предыдущей главе. Уже открытые главы старых сохранений сохраняются.

Инструменты разработчика, кнопки пропуска волн и горячие клавиши включаются параметром `?dev=1`, например `index.html?dev=1`. Альтернатива для тестового хоста — установить `window.SURVIVORS_DEV = true` перед основным скриптом игры.

Проверка загрузки ресурсов, прогрессии, автопаузы, рекламного звука, облачных миграций и иконок:

```sh
node scripts/test_web_platform_fixes.js
```

Проверки боссов:

```sh
node scripts/verify_boss_pipeline.js
node scripts/test_strict_boss_abilities.js
node scripts/test_canvas_save_restore_stack.js
```

Платформенный мост находится в `js/platform.js`. SDK целевой площадки должен быть подключён до него. Игра ожидает инициализацию моста и загрузку сохранения перед показом кнопки входа, затем отправляет `gameReady` один раз. Проверки используют заглушки SDK; интеграцию с каждой площадкой необходимо проверить в её тестовом окружении.
